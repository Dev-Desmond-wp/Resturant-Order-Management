 Restaurant Order Table

A simple and modern web app that helps restaurants manage food orders and table bookings easily.

Customers can browse the menu, place orders, and reserve a table in minutes. 
Staff can view and manage all orders from one place.



 Features

 View full restaurant menu with food  and prices
  place order
   Search and filter food by category
   Track order status - Pending, Preparing, Served
  Fully responsive - works on phone and laptop
  Fast and easy to use
